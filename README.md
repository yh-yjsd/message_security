# **信息加密器v2.0.0 rel**

加密功能实质是对信息进行混淆。压缩功能通过自适应算法对文本进行字符数或占用空间压缩并具有混淆功能。

## **已有功能**

(截至v2.0.0 rel)
采用自定义加密算法，可实现对称加密(混淆)文字和图片。  
拥有调色盘换肤 + 预设主题 + 亮暗模式，三种密文输出形式。  
同时支持文本/文本文件压缩功能，拥有base512/base64(urlsafe)输出模式。  
对于重复率高的文本(特别是汉字)拥有极高的压缩效率。
