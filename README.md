# **信息加密器**

下面是画的大饼：用于对聊天等信息进行加密，综合对称和非对称加密。拥有密钥交换便捷，初始化便利等优点。其安全性可以胜任日常沟通交流，但不建议用于加密其他秘密。

## **已有功能**

(截至v1.5.9 rel)
采用自定义加密算法，可实现对称加密(混淆)文字和图片
拥有调色盘换肤 + 预设主题 + 亮暗模式，三种密文输出形式。
